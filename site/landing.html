The CLI

Everything the TUI does, one command away.

Same player, same queue, from any shell, script or window-manager keybinding. Fuzzy names everywhere, --json on every listing.

  • Status bars: goose now --format '{title} — {artist}'
  • Media keys: bind goose toggle and goose next
  • Completion for zsh, bash, fish and PowerShell, artist and album names included

CLI reference →

zsh
goose play "8th Day" lucky       # fuzzy album names
goose radio fried                # endless radio
goose download "8th Day" --top   # save for offline
goose artists | fzf | xargs -I{} goose play {}
