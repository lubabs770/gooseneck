Picking a theme

In the TUI press t for a picker with live preview: move through the list and the whole app repaints as you go. The pick lasts until you quit; to make it the default, set it in the config:

goose config set theme tokyonight
goose config set theme auto        # back to the default

The CLI's colours follow the same theme.

Omarchy: follows your desktop

The default theme is auto. On Omarchy that means the omarchy theme: gooseneck reads the current Omarchy theme's colors.toml and repaints live when you switch with omarchy theme set, no restart needed. Anywhere else, auto means opencode.

Your terminal's colours

The system theme uses your terminal's own palette and background, so gooseneck blends into whatever you already have.
