goose radio "8th Day"     # start
goose radio               # what's on
goose radio stop          # end it (queued tracks keep playing)

In the TUI, select an artist and press m. mix is an alias for radio.

How it picks songs

  1. The first batch (30 tracks, change with -n) mixes the seed artist with related artists that are in the catalog.
  2. When three or fewer tracks are left, the background daemon adds 25 more.
  3. Each new batch is seeded by the original artist about a third of the time, otherwise by a related artist that hasn't been used in the last five batches. Each new seed's relatives widen the pool, so the station slowly wanders.
  4. No track repeats within a session.

What ends it

  • Playing something else (replacing the queue).
  • goose radio stop.
  • Shutting the player down.

Adding to the queue (--add, --next, a, A) does not end the radio.

Radio top-ups aren't written to your play history, so goose history stays readable. Listens still scrobble normally.
