goose download "8th Day" lucky        # one album
goose download "8th Day" lucky 4      # one track
goose download fried --top            # an artist's top songs
goose download fried                  # everything they've released
goose downloads                       # what you have
goose downloads rm "8th Day" lucky    # delete an album

In the TUI press D on anything. Downloads run one job at a time with a progress bar; queue up as many as you like. dl is an alias.

Where files go

To download_dir, by default ~/Music/gooseneck (or $XDG_MUSIC_DIR/gooseneck), laid out as:

~/Music/gooseneck/<Artist>/<Album>/NN - Title [videoId].m4a

yt-dlp saves the best audio, m4a when available, and tags it when ffmpeg is installed. The [videoId] in the name is how gooseneck recognises the file as the same track.

How playback uses them

  • Every play checks for a local copy first, so downloaded tracks play from disk, even offline.
  • Re-running a download only fetches what's missing.
  • Each track gets 3 attempts with 3 downloads in parallel, because YouTube's 403s are often temporary.
goose config set download_dir ~/Music/jewish
