The one-liner

curl -fsSL https://raw.githubusercontent.com/lubabs770/gooseneck/main/install.sh | sh

This downloads the latest release for your OS and CPU and installs gooseneck-player plus the short alias goose into ~/.local/bin. Make sure that directory is on your PATH.

VariableDoes
BIN_DIR=Install somewhere else, e.g. BIN_DIR=/usr/local/bin
VERSION=Pin a release, e.g. VERSION=v0.4.0
curl -fsSL https://raw.githubusercontent.com/lubabs770/gooseneck/main/install.sh | BIN_DIR=/usr/local/bin sh

Windows: grab the .exe from the releases page. Playback works, but it's fire-and-forget for now (no pause/skip from other terminals yet).

Requirements

  • mpv plays the audio.
  • yt-dlp fetches streams and downloads. Keep it fresh, since YouTube changes often.
  • Optional: ffmpeg tags downloaded files, and mpv-mpris puts gooseneck in your desktop's media controls.
# Arch / Omarchy
sudo pacman -S mpv yt-dlp ffmpeg mpv-mpris
# macOS
brew install mpv yt-dlp ffmpeg
# Debian / Ubuntu
sudo apt install mpv ffmpeg && pipx install yt-dlp

Shell completion

Artist and album names complete too, so goose play 8th<tab> just works.

goose completion zsh > "${fpath[1]}/_goose"
goose completion bash > ~/.local/share/bash-completion/completions/goose
goose completion fish > ~/.config/fish/completions/goose.fish

Updating & uninstalling

Re-run the installer to update. To remove gooseneck, delete the two binaries and, if you like, its data:

goose quit-player
rm ~/.local/bin/goose ~/.local/bin/gooseneck-player
rm -r ~/.config/gooseneck      # config, cache, history, scrobbles

Downloads live in ~/Music/gooseneck and are not removed by the above.
