Build from source

git clone https://github.com/lubabs770/gooseneck
cd gooseneck/player
go build -o gooseneck-player .
go vet ./... && go test ./...

CI tests and cross-compiles linux/macOS/windows × amd64/arm64 on every change, and publishes a release for v* tags.

Find your way around

Architecture notes for contributors (and AI agents) are in LLM.md. The short version:

PackageRole
internal/libraryThe service layer: catalog, cache, YouTube Music, player, history. Put logic here.
internal/cliCobra commands
internal/tuiThe Bubble Tea app
internal/ytmRead-only YouTube Music client
internal/mpvThe headless mpv daemon over JSON IPC
internal/storeSQLite cache and history
internal/catalogartists.json, tags, fuzzy search, multi-catalog merge

Test without touching your setup

GOOSENECK_HOME=$(mktemp -d) go run . play "8th Day" lucky

This website

It lives in site/: plain HTML fragments and a dependency-free Python script. Theme colours are read from the TUI's source, so they never drift.

python3 site/build.py      # writes site/dist/
python3 -m http.server -d site/dist
